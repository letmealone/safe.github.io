안전워치 시안 사용 안내

담당자의 점검·검토 업무와 공개 정보조회 흐름을 직접 체험하는 시안입니다. 모든 건물·점검자료·모델은 예시이며 실제 시스템과 연결되지 않습니다.

시안 시작하기

담당자 업무 체험

  1. 첫 화면의 업무시스템 로그인을 선택합니다.
  2. 전문기관 담당자 또는 지자체 담당자를 선택하고 로그인 후 메인화면 보기로 들어갑니다. 실제 계정은 필요하지 않습니다.
  3. 대시보드에서 최근 작업을 이어가거나 점검 현황·점검 이력을 엽니다.
  4. 주민회관의 BIM 보기 또는 이 회차 BIM을 눌러 층·결함·회차별 근거를 살펴봅니다.
  5. 지도 분석에서 대상을 찾고, 내 업무로 돌아와 기존 업무를 이어갑니다.

전문기관의 보고서 공유 → 지자체의 보완 요청 → 기관의 보완 공유 → 지자체 재검토를 가상으로 체험할 수 있습니다.

로그인 없이 공개 정보 보기

첫 화면에서 공개 지도 바로 보기를 선택하세요. 경기 → 고양시 → 일산동구 → 장항1동 → 예시 주민회관으로 이동하면 공개 요약과 공개용 3D를 볼 수 있습니다.

지도는 휠로 확대·축소하고 드래그로 이동합니다. 이 화면 범위에서 조회를 눌러 조회 범위를 확정합니다.

주요 화면 바로 보기

  • 점검 현황
  • 점검 상세
  • 점검 이력
  • 회차·버전별 BIM 선택
  • 과거 회차 BIM

단계 미리보기는 독립된 예시입니다. 전체 체험은 첫 화면에서 시작하세요.

기록과 자료의 범위

가상 작성 내용과 조회환경은 현재 브라우저에 보관됩니다. 다른 기기나 브라우저와 공유되지 않으며, 시안 기록 초기화로 지울 수 있습니다. 실제 로그인·서버 저장·사용자 간 자료 공유 기능을 제공하는 운영 서비스는 아닙니다.

시·도 경계는 2021년, 고양시 경계는 2020년 자료를 단순화했습니다. 구·동 구획과 건물 위치·주소·점검자료·모델은 가상입니다. 최신 행정경계나 실제 안전진단 정보를 제공하지 않습니다.
